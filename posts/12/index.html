Docker学习笔记

发表于2026-08-11|更新于2026-08-11|学习笔记
|浏览量:

今天第一次使用Docker,是在树莓派上安装SnowLuma和AstrBot的时候,不想配置环境,去了解了下Docker

概念(个人理解)

Docker是将一个软件需要的环境一起打包,只要一台设备上能运行Docker,镜像支持设备的架构,就可以运行Docker打包的软件

镜像和层

镜像

镜像:软件+环境打包

层

镜像是由许多层组成的

镜像由哪些层组成,写在源码仓库中的Dockerfile

以astrbot为例https://github.com/AstrBotDevs/AstrBot/blob/master/Dockerfile:

可见,层自底向上构建的,从最基础的Python(From python)到装依赖,启动程序

层 指令 作用
1 FROM python:3.12-slim 地基：Debian 精简版系统 + 已装好的 Python 3.12，slim 版本比完整版小很多
2 WORKDIR /AstrBot 创建工作目录，后续所有操作都在这个目录下进行
3 COPY . /AstrBot/ 把项目源码（主程序、插件、配置模板）复制进镜像
4 RUN apt-get … 安装系统级依赖 + Node.js，同一层内顺手清理缓存
5 RUN pip install uv … 装 uv 并用它安装项目全部 Python 依赖
6 EXPOSE 6185 声明容器监听 6185 端口（Web 管理面板），0B 元数据
7 CMD [“python”, “main.py”] 容器启动时执行主程序，0B 元数据

可见,有的环境是比较常见的,例如python3.12,docker其他镜像也可以基于电脑上已有的层,不必重新下载

我认为Docker方便的点就在1.环境打包,开箱即用 2.镜像可以基于已有的层

容器

容器：镜像的运行实例，相当于“对象”，运行时会多一层可写层，进程的所有改动（写文件、装东西）都落在这层；删容器不删镜像；改容器内部不影响镜像。
