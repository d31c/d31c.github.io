ARP（Address Resolution Protocol）是工作在网络层（L3）与数据链路层（L2）之间的协议，其核心功能是将IPv4地址解析为对应的MAC地址（物理地址）。

ARP欺骗:攻击者侦听到合法主机的ARP请求后，抢在真实主机之前发送伪造的ARP应答，利用时间差率先污染请求者的缓存。

  • 断网攻击：数据包进入攻击者网卡后，在链路层/IP层入栈处被直接丢弃
  • 中间人攻击：数据包发到攻击者 → 攻击者转发到网卡 → 发往真实目标

  1. Frame 6113 帧信息 → 抓包元数据（不属于任何协议层，只是统计信息）
  2. Ethernet II 以太网 → 数据链路层（TCP/IP链路层）
  3. IPv4 网际协议 → 网络层（TCP/IP网际层）
  4. TCP 传输控制协议 → 传输层（TCP/IP传输层）
  5. [55 Reassembled TCP…] → TCP附加解析提示（属于TCP层附属信息）
  6. HTTP 超文本传输协议 → 应用层（TCP/IP应用层）
  7. MIME multipart/form-data → HTTP载荷内容，仍属于应用层

防御建议

  1. 静态ARP绑定：在路由器或终端中手动绑定IP-MAC映射，可彻底免疫ARP欺骗。
  2. ARP防火墙：个人电脑可安装火绒等软件，开启ARP攻击拦截功能。
  3. 使用HTTPS：加密通信能防止数据被截获后解析。
